# Naming of different aspects

The naming is based around the Library of Alexandria, this is because the
original purpose of the project was the design and storage of an efficient
home-based cloud storage. I took that initial goal and decided to extend that
into more different projects within that initial project goal. One thing I had
always wanted to do was completing a Linux From Scratch (LFS) installation, but
one thing that always held me back was the limitation of it being something
that I could see as being reliable and most importantly manageable long-term.
From this I decided I would start in the creation of a package manager.

## Scribe

I decided on the name Scribe for my package manger, since it makes a lot of
semantic sense to me. Something that would keep a record and manage everything
I would have installed and related to Library of Alexandria made most sense to
be Scribe, it is also simply something that is easy and short to type. My
package manger will also be based around `toml` recipes so I can then refer to
these recipes as *scrolls*, which is quite nice.
