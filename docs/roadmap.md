# Roadmap

First is making a package manager - *Scribe* - which I will use to make the
Linux base for all that will come next. Next is making the Linux From Scratch
(LFS) implementation such that I can have it easily automated for migrating my
system across to new hardware. The LFS system will not initially have a head to
make it as efficient as I can. Then I will begin on implementing the cloud
storage system I had had as the initial goal. Once the cloud storage is in
place I will then create a website for nice easy access.
